# INOFY

> **2026-10-11 memory-policy precedence:** [VIVY #58](https://github.com/ProjectViVy/agent-vivy/issues/58) and [#57](https://github.com/ProjectViVy/agent-vivy/issues/57) supersede the earlier unconditional ACTMEM context exclusion only for the selected unified VIVY policy. LIFE is the first default-enabled pilot; coding is excluded in phase one. Persistent sessions of one VIVY subject share one free-form Recap/revision stream; delegated workers have no default Recap/persona entitlement. WORLD remains tool-only and excluded from automatic context. INOFY supplies orchestration, not a memory authority, second runtime or LIFE pipeline. The old parity requirements/tests below remain evidence for their baseline; selected-policy compatibility, shared-revision conflicts and Work/reconcile/capture consumers require planned work, not code deletion or new completed checkboxes.

The root Go package exports `DefinitionSchema()` for authoring clients. Its
JSON Schema is a projection of the strict decoder's executable vocabulary;
`DecodeArtifact`, `ValidateDefinition`, and the trusted node catalog still
govern admission. In particular, schema validation alone cannot prove
duplicate-key safety, reference scope, graph topology, or host authority.

An embeddable Go workflow engine built on Eino, with a standalone application and reusable visual editor for ViVy and Garden.
