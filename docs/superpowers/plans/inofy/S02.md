# S02 — Strict Definition and Digest Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single strict semantic format validates identically for all authors and yields stable digests while layout edits remain presentation-only.

**Architecture:** `internal/definition` owns decoding, graph/schema checks, normalized encoding and digests; root exports small adapters. Portable schema fixtures are the shared contract for Go and browser.

**Tech Stack:** Go, `santhosh-tekuri/jsonschema/v6` (verify v6.0.2 against the two host modules), standard `encoding/json`/SHA-256.

**Spec:** [architecture](../../specs/2026-09-28-inofy-architecture.md) §§4, 5, 15 (G1); [index](index.md). Baseline S01 accepted public types.

## Global Constraints

- `schema_version: "inofy.workflow/v1"`; tagged `call|switch|select|repeat`; unknown executable fields, duplicate object keys, authored `$` or `/` IDs are errors.
- `inofy-normal-v1`: finite binary64, safe integers only, negative zero -> zero, sorted object keys/nodes/edges, ordered cases preserved, HTML escaping off.
- Only local `$ref` JSON Schema 2020-12; portable profile from architecture §4.1. Presentation may preserve unknown presentation fields and cannot carry executable behavior.

## Review Focus

- Duplicate nested key rejects before `encoding/json` silently chooses the later value (Task 1).
- Numeric `9007199254740992` and non-finite input reject; `-0` yields canonical zero (Task 2).
- An omitted binding differs from an explicit `null` literal (Task 1).
- Remote `$ref` and unsupported schema keywords fail closed without fetching (Task 1).
- Rearranging canvas coordinates changes ArtifactDigest only (Task 2).
