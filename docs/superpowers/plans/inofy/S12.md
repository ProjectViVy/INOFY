# S12 — Garden Fast/Deep Recall and Ingestion Adapter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Garden's actual Fast and Deep Recall paths use INOFY orchestration while preserving Frozen Core, card/evidence boundaries, outputs, warnings, budgets and ingestion identity.

**Architecture:** Garden binds trusted principal/profile/session and supplies narrow domain node executors. Start with Fast Recall behavior corpus; Deep Recall adds optional planner/branches; configured pipeline YAML is not assumed to be the live path.

**Tech Stack:** Go, Garden `agentapi` and `internal/recall`, existing Mentle/Laputa calls, INOFY library.

**Spec:** [architecture](../../specs/2026-09-28-inofy-architecture.md) §§10, 15 G8; [index](index.md). Verified laputa HEAD `384d54d3a5b98dc00e9c87bcd359c8d55c7ab5ad`. Read `../laputa/AGENTS.md`, Garden scoped AGENTS, ADR-0012 before edits.

## Global Constraints

- Frozen Core six allowed projections; WORLD.MD and ACTMEM.MD are tool-only, never automatic context; ContextView is disposable, Mentle owns evidence.
- Preserve card-before-evidence, caps/degradation, exact profile/session scope and ingestion accepted-vs-completed/dedup conflict behavior.
- No double orchestration manager or second ingestion queue; optional recurrence applies only to explicitly enabled pipeline and honors the one-level repeat cap.

## Review Focus

- Cross-profile card or evidence input cannot enter a node through authored JSON (Task 1).
- WORLD/ACTMEM never enter Fast/Deep automatic ContextView even with malformed definition (Task 1).
- Missing planner/LLM preserves degraded Deep Recall warnings and existing budget (Task 2).
- Duplicate ingestion event identity yields existing receipt, conflicting payload rejects (Task 3).
- Baseline normalizations exclude only trace timestamps/IDs, not domain output/limits (Task 1).
